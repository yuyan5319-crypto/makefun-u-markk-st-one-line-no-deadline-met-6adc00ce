A program that writes one single-line joke giving an excuse for a missed deadline — that line and nothing else. Running it writes the line to `/output/entry.txt`.

The line (119 characters, one sentence):

> I missed the deadline because I emailed it asking for an extension and it replied 'per my last email' — so here we are.

The joke's turn: the deadline itself answers back in corporate speak, so the excuse and the punchline are the same sentence — an apology that blames the deadline for being unhelpful.

## Run it

```sh
python3 main.py
```
